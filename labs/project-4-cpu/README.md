# Project 4 – Processor Core Design

## Overview
Implements the **Duke 250/16** CPU: a single-cycle, 16-bit MIPS-like RISC processor in Logisim Evolution. Supports a custom instruction set including arithmetic, logic, shifts, memory access, branching, jumping, and basic I/O.

## Key Features
- Harvard architecture (separate instruction and data memory).
- 8 general-purpose registers (`$r0`–`$r7`), with `$r0` hardwired to 0 and `$r7` as the link register.
- Proper asynchronous reset behavior for PC, registers, TTY, and keyboard buffer.
- Correct rising/falling edge clocking for components per specification.

## Contents
- `cpu.circ` – Complete processor design.
- `cpu.pdf` *(optional)* – Description of working and non-working components for partial credit assessment.

## Requirements
- Only approved Logisim components may be used.
- Register file must use tri-state buffers and a decoder (not a multiplexer).
- Must pass automated tests using provided assembler and simulator output.

## How to Run
1. Load `cpu.circ` in Logisim Evolution.
2. Load program ROM and RAM images generated by the provided assembler.
3. Apply `reset` and run the clock to execute programs.
4. Use `hwtest.py` for automated verification.
